PART E. 절대 규칙 (틀리면 글 전체가 오정보)
1. ★숙박 체험단 소재(한국 국내 숙소 각도 포함)는 당분간 작성 금지(2026-08-12 사용자 지시). 표 A는 사실 확인용일 뿐 주제로 쓰지 않는다.
2. "업계 1위·최고·유일"류 최상급 표현 금지(표시광고법 리스크).
3. 가격·조건·기간·절차는 PART C 표 값만. 표에 없으면 "캠페인 조건 확인 후 안내"로 열어 둔다. '무조건 가능' 단정 금지.
4. 외부 사실(쇼피·틱톡샵 입점 정책, 베트남 무비자·항공·관광 통계, 위생허가 절차·기간, 공정위 「추천·보증 등에 관한 표시·광고 심사지침」의 대가성 표기 의무, 각국 이커머스 규정 등)은 반드시 당일 웹검색으로 재확인. 확실치 않은 수치는 아예 쓰지 않는다.
5. 체험단·인플루언서 협찬 콘텐츠는 공정위 지침에 따라 경제적 이해관계(대가성) 표기 의무가 있고 광고주도 표기 책임을 공유한다 — 체험단·리뷰 글에서는 이 사실을 정확히 안내.
6. 경쟁사 실명·특정 업체 지목 금지. "일부 대행사", "타사 사례"까지만.
7. 클라이언트 상호·대표명 금지 — 업종+지역까지만(예: 경기도 화장품 브랜드사, 호치민 1군 스파).
8. 없는 경험·사례 창작 금지. 사례는 실제 진행 건 성격(업종·지역·구조)만, 수치가 없으면 숫자를 쓰지 않는다("재계약", "추가 캠페인 확대"처럼 사실만).
9. 독자는 한국 광고주. 소비자 대상 여행 정보 글로 흐르지 말 것. Threads의 반말·음슴체 금지.

PART F. 자주 쓰는 용어 정의 (혼동 금지)
- KOL = 팔로워 규모가 큰 인플루언서(인지도 중심) / KOC = 팔로워는 작지만 구매 후기·리뷰 신뢰가 높은 소비자형 인플루언서(전환 중심). 베트남 현지 마케팅에서 KOC 다수 구조는 판매 전환용, KOL 소수는 인지도용.
- 크로스보더 = 현지 법인 없이 한국에서 해외 마켓플레이스(쇼피·틱톡샵·라자다 등)에 직접 판매하는 구조.
- 체험단 = 제품·서비스를 제공받은 인플루언서·소비자가 실제 체험 후 콘텐츠를 발행하는 캠페인. 대가성 표기 필수.
- 베트남 화장품 위생허가(공표) = 베트남에서 화장품을 정식 유통하려면 필요한 등록 절차. 절차·기간·기관명은 당일 웹검색으로 확인한 값만 쓴다.

## 네이버 블로그 채널 (2026-09-17 신설)

작성기에서 브랜드 **트래비티** → 채널 **「네이버 블로그 (광고주용)」** 를 고르면
`prompt_naver.md`(트래비티 네이버 프롬프트 v2.0 + 앱 조정)가 통째로 적용된다.

### 쓰는 법
1. 메인키워드 / 서브키워드 / 제목을 넣는다. 제목을 넣으면 **그대로** 쓰고, 비우면 프롬프트의 제목 규칙으로 짓는다.
2. 사진 폴더는 `E:\6. TREVITY\트래비티_사진` (하위 폴더 포함). 키워드에 맞춰 자동 선별된다.
   - 베트남 현지 캠페인 실사는 `베트남사이트_캠페인\` (vn.trevity.com에서 수집, 접두어 `vn사이트_`)
3. 카드 디자인은 **디자인 2(cards_2 매거진)** 가 기본.
4. 생성 → 본문 + (사진N) 슬롯 + 카드뉴스 + ===TAGS===/===ANALYSIS===/===META=== 가 한 번에 나온다.

### 이 채널이 강제하는 규칙 (프롬프트 v2.0)
- 본문 공백 제외 **1,800~2,200자**
- 처음부터 끝까지 존댓말 ~요체 (반말 전환 없음, `~다` 단정형 금지)
- 부제(⌐) 줄과 상단 광고 주체 표기 블록 **없음**
- **넓은 키워드로 유입 + 본문 후반은 베트남 현지 실무**로 채움
- 착지(트래비티) 블록은 글마다 다른 소제목 · 서비스 2~3개만
- **카드뉴스 = 표지 1장 + 본문 소제목마다 1장** (문단 안 세부 항목을 카드로 쪼개지 않음)
- 사진 슬롯 = 도입 1개 + 소제목마다 1개 (카드와 1:1)
