# 하오커뮤니케이션 사실 기준서

하오커뮤니케이션(주)은 6년 연속 정부지원사업 공식 수행기관이다. 수출바우처·혁신바우처·판로개척지원사업 3개 정부사업을 통합 수행한다(누적 수행 실적 412건+). 아래 사실만 쓰고, 없는 수치·고객사·실적은 지어내지 않는다.

## 4개 전문 센터 (원스톱)
- **디자인센터** (design.haoc.co.kr): 카탈로그·브로슈어(제품·회사소개), 팜플렛·리플렛, 포스터·전단지, CI·로고, 패키지·라벨, 다국어 디자인(수출용 영문·중문 등). 기획부터 인쇄까지 원스톱. 누적 4,500건+ 제작(10년), 재의뢰율 98%, 5개국 다국어 대응(영어·중국어·일본어·프랑스어 등). 프로세스: 문의·상담 → 견적·계약 → 기획·디자인 → 수정·검수 → 인쇄·납품.
- **웹구축센터** (web.haoc.co.kr): 반응형·다국어 홈페이지, 쇼핑몰·CMS, 모바일 앱·시스템, SEO·AEO 최적화(생성형 AI가 브랜드를 인용하도록 구조화 데이터 설계), 리뉴얼·유지보수. 일반 기업 홈페이지 기준 4~8주. 프로세스: 상담·견적 → 기획·설계 → 디자인 → 개발·구축 → 런칭·운영.
- **스튜디오센터** (studio.haoc.co.kr): 제품·브랜드 촬영, 상세페이지 디자인, 영상·릴스, 인·익스테리어 촬영, 보정·리터칭. 완료 프로젝트 1,603건, 협력 브랜드 1,203개, 누적 촬영 111,360컷, 재의뢰·만족도 98%. 프로세스: 문의·상담 → 견적·일정 → 콘티·연출 → 촬영·컨펌 → 보정·납품.
- **마케팅센터** (mkt.haoc.co.kr): 브랜드 마케팅 현황 진단, 핵심 메시지·전략 수립, 콘텐츠 제작·노출(SNS·숏폼·상세페이지·PR·SEO·AEO), 수출상담회·이커머스 등 글로벌 통합 마케팅. 프로젝트 경험 900개+. 진단부터 실행까지 전담팀 밀착 운영.

## 타겟·콘텐츠 방향
- 타겟: 정부지원사업(수출바우처·혁신바우처·판로개척)을 활용하려는 중소기업·수출기업 대표.
- 이들의 진짜 질문 형태: [○○ 업종/수출국/상황인데] + [바우처로 이것도 돼? / A가 나아 B가 나아 / 비용·기간 얼마 / 수행기관 뭘 보고 골라]. 글은 이 질문의 '답'이 되게 쓴다.
- 규격(mm·면수·페이지수)·기간·수량·언어 수 같은 '근거가 되는' 숫자를 핵심 지점 2~4곳에만 넣는다(숫자 도배 금지). 수량·규모는 용도에 맞는 근거로(수출상담회·전시 배포용은 많이, 단일 기업 소개용은 적게).
- 회사 실적 수치(412건+·6년 연속·3개 사업·4개 센터·98% 등)는 마무리에서만, 주제에 맞는 1~2개만.
